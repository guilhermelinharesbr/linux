#### yum

Gerenciador de Pacotes padrão ALTO nível para o S.O. Fedora 21(2014) pra trás, CentOS 7(2014) pra trás. É um comando para gerenciar arquivos .RPM. Lançado em 2003.

---

#### yum update

Atualiza repositórios automaticamente.

Ex:
```bash
sudo yum update
```
