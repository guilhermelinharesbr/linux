#### CTRL + A

Serve para o cursor ir para o início da linha.

---

#### CTRL + C

Cancela um comando.

---

#### CTRL + D

Para fechar o terminal.

---

#### CTRL + E

Serve para o cursor ir para o fim da linha.

---

#### CTRL + L

Serve para limpar a tela do terminal.

---

#### CTRL + R

Serve para pesquisar comandos já utilizados. 

Usando o CTRL + R e depois digitando ssh ele irá autocompletar com  ssh guilherme@192.168.1.100 e caso esse não seja o comando que desejado basta apertar CTRL + R novamente para ele ir mostrando os outros comandos utilizados com a palavra ssh nele.

---

#### CTRL + U

Para apagar tudo o que estiver a esquerda do cursor no terminal.

---

#### CTRL + Z

Para parar a execução de um processo rodando em primeiro plano, basta pressionar as teclas CTRL+Z. O programa em execução será pausado e será mostrado o número de seu job e o aviso de comando.

Para retornar a execução de um comando pausado, use **fg** ou **bg**.

O programa permanece na memória no ponto de processamento em que parou quando ele é interrompido. Você pode usar outros comandos ou rodar outros programas enquanto o programa atual está interrompido.

---

#### TAB

É o autocomplete no terminal Linux, mas se ela estiver com caracteres separados pode-se usar a sequência \ TAB, traduzindo barra invertida, espaço, TAB.
